# Project Guidelines

## Tech Stack

- React
- JavaScript
- HTML
- CSS

## Coding Conventions

- Use functional React components.
- Keep components small and reusable.
- Use meaningful variable and function names.
- Avoid unnecessary complexity.
- Write clean and readable code.
- Prefer simple solutions over premature abstraction.

## Git Conventions

All commits must follow Conventional Commits.

Examples:

- feat: add navbar
- fix: resolve mobile layout issue
- docs: update README
- refactor: simplify component structure
- chore: update dependencies

## AI-Assisted Development

Cursor may be used for:

- Code generation
- Debugging
- Refactoring
- Documentation
- Code review

AI-generated code should always be reviewed and understood before committing.

## Development Workflow

1. Understand the requirement before writing code.
2. Use Cursor for AI-assisted development when appropriate.
3. Review and understand AI-generated code before accepting it.
4. Test changes locally before committing.
5. Use Conventional Commits for all Git commits.
- Keep the project structure simple and maintainable.
